# Copilot Instructions for TRILUX Security Platform Landing Page

## Project Overview
You are building a comprehensive, modern landing page for **TRILUX** - a cutting-edge AI-powered security framework company. This is a multi-stage development process where each stage builds upon the previous one to create a world-class marketing website.

## Tech Stack & Architecture
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom design system
- **UI Components**: shadcn/ui (Radix UI primitives)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Theme**: Dark/Light mode support with next-themes
- **Charts**: Recharts for data visualization

## Design Philosophy & Brand Identity

### Brand Positioning
- **Company Name**: TRILUX
- **Tagline**: "AI-Powered Security Framework for the Modern World"
- **Mission**: Comprehensive security analysis across web applications, mobile apps, browser extensions, LLM testing, and infrastructure
- **Target Audience**: Security researchers, DevOps teams, enterprise security departments, compliance teams

### Visual Identity
- **Primary Colors**: 
  - Primary: `hsl(142 86% 28%)` (Security Green)
  - Secondary: Various security-themed gradients
- **Typography**: Poppins font family (configured with weights 300, 400, 500, 600, 700)
- **Design Language**: Modern, professional, security-focused with glass morphism effects
- **Iconography**: Shield, lock, security-focused icons from Lucide React

## Development Stages

### Stage 1: Landing Page Hero & Navigation
**File**: `/app/landing/page.tsx`

Create the main landing page with:

#### Hero Section
- **Layout**: Full-height viewport section with centered content
- **Background**: Gradient with subtle animated particles or grid pattern
- **Content Structure**:
  ```tsx
  - Company logo/brand
  - Main headline: "AI-Powered Security Framework"
  - Subheadline: "Comprehensive security analysis for modern applications"
  - Key value propositions (3-4 bullet points)
  - Primary CTA: "Join Waitlist" button
  - Secondary CTA: "View Demo" button
  - Trust indicators (logos of security frameworks/compliance standards)
  ```

#### Navigation
- **Sticky header** with transparent background that becomes solid on scroll
- **Navigation items**: Products, Solutions, Pricing, Resources, Company
- **Right side**: Join Waitlist (primary) and Login (secondary) buttons
- **Mobile**: Hamburger menu with slide-out navigation

#### Key Features
- **Responsive design**: Mobile-first approach
- **Performance**: Optimized loading with proper image optimization
- **Accessibility**: ARIA labels, semantic HTML, keyboard navigation
- **SEO**: Proper meta tags, structured data

### Stage 2: Product Features & Benefits

#### Products Showcase

1. **Product Grid**: 3x2 or 2x3 grid of product cards

   - Brief description (2-3 lines)

3. **Interactive Elements**:

#### Security Metrics Display
- **Real-time style counters**: Number of vulnerabilities detected, scans performed, etc.
- **Trust badges**: Compliance certifications (SOC2, ISO 27001, etc.)
- **Statistics**: Customer testimonials, uptime guarantees

### Animation Guidelines
Use Framer Motion for:
- **Scroll-triggered animations**: Fade in, slide up
- **Hover effects**: Scale, glow, elevation
- **Page transitions**: Smooth navigation
- **Loading states**: Skeleton loaders, progress indicators

### Responsive Design
- **Mobile-first**: Design for 375px width minimum
- **Breakpoints**: sm (640px), md (768px), lg (1024px), xl (1280px)
- **Touch targets**: Minimum 44px for interactive elements
- **Typography scale**: Responsive text sizing

### Performance Optimization
- **Image optimization**: Next.js Image component
- **Lazy loading**: Intersection Observer for sections
- **Code splitting**: Dynamic imports for heavy components
- **SEO optimization**: Meta tags, structured data

### Accessibility Requirements
- **Semantic HTML**: Proper heading hierarchy
- **ARIA labels**: Screen reader support
- **Keyboard navigation**: Focus management
- **Color contrast**: WCAG AA compliance
- **Alternative text**: Images and icons
